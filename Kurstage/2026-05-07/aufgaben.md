# Aufgabe 1

Erstelle eine Page `/ShowCookie`, die den Inhalt (Wert) zu einem selbstgewählten Cookie-Namen (Schlüssel) anzeigt.

Erstelle außerdem eine Page `/SetCookie`, die dem Nutzer ein Formular anzeigt, mit dem er den Inhalt desselben Cookies auf einen konkreten Wert ändern kann.

Im Netzwerk-Tab der Developer-Tools deines Browsers kannst du sehen, wie der Webserver in der Antwort das Cookie entsprechend setzt.

# Aufgabe 2

Erweitere die Page `/ShowCookie` derart, dass sie nicht nur das selbstgewählte Cookie anzeigt, sondern alle Cookies, die der Client zum Server geschickt hat.
